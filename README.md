# 🤖 Telegram Subscription Bot

Бот для платних підписок на Telegram-канал з оплатою через LiqPay.

## Можливості

- Оплата через LiqPay (Visa/Mastercard, українські картки)
- Одноразові invite-посилання (1 посилання = 1 людина)
- Автоматичне нагадування за 3 дні та за 1 день до кінця підписки
- Автоматичний кік після закінчення підписки
- Адмін-панель: статистика, ручне управління, розсилки
- Захист від дублікатів платежів

---

## Структура файлів

```
bot.py           — запуск бота
config.py        — всі налаштування
database.py      — робота з базою даних
liqpay.py        — інтеграція з LiqPay
scheduler.py     — планувальник (нагадування, кік)
handlers/
  user.py        — команди для користувачів
  admin.py       — команди для адміністраторів
  payments.py    — webhook від LiqPay
```

## Налаштування

### 1. Створи бота
- Відкрий @BotFather → /newbot
- Скопіюй токен

### 2. Підготуй канал
- Створи **закритий** (private) канал
- Додай бота як **адміністратора** каналу
- Права боту: запрошення користувачів, видалення учасників
- Дізнайся ID каналу через @userinfobot

### 3. Реєстрація LiqPay
- Зайди на liqpay.ua
- Бізнес → Мій бізнес → Ключі
- Скопіюй публічний та приватний ключі

### 4. Заповни .env
```bash
cp .env.example .env
# Відкрий .env і заповни всі значення
```

### 5. Зміни config.py
- `CHANNEL_NAME` — назва каналу
- `CHANNEL_DESCRIPTION` — що отримає підписник
- `PLANS` — тарифи і ціни
- У файлі `handlers/user.py` знайди `your_bot_username` і заміни на username бота

## Запуск локально (для тестування)

```bash
pip install -r requirements.txt
python bot.py
```

Для тестування webhook LiqPay локально використай ngrok:
```bash
ngrok http 8080
# Скопіюй https URL і встав в SERVER_URL в .env
```

---

## Деплой на Railway

1. Завантаж код на GitHub
2. Зайди на railway.app → New Project → Deploy from GitHub
3. Вибери репозиторій
4. В розділі Variables додай всі змінні з .env
5. Railway автоматично дасть HTTPS URL — встав його в `SERVER_URL`

## Команди бота

### Для користувачів
| Команда | Дія |
|---------|-----|
| /start | Головне меню і тарифи |
| /status | Статус підписки |
| /getlink | Отримати посилання на канал |
| /help | Довідка |

### Для адміністраторів
| Команда | Дія |
|---------|-----|
| /admin | Панель зі статистикою |
| /find @username | Знайти користувача |
| /give @username 30 | Дати доступ на N днів |
| /kick @username | Видалити користувача |
| /broadcast текст | Розіслати всім підписникам |
